# desyn-raster

The Desyn renderer (Rust, edition 2024): display lists from design pages with stable layer keys and damage
rectangles, a tiny-skia rasterizer (all node types, fills, strokes, effects, 16 blend modes, masks, image
adjustments, text, SVG, charts, tables, QR codes), and the exporters (PNG, JPEG, WebP, SVG, PDF, PPTX, GIF, frame
sequences) plus the `desyn-render` CLI. Native and `wasm32-unknown-unknown`.

**API overview: [API.md](API.md).** Golden fixtures: `spec/fixtures/render/` (see its README).

## Verify

```sh
cd crates/desyn-raster
export CARGO_TARGET_DIR=$PWD/../../target/desyn-raster CARGO_BUILD_JOBS=6
cargo fmt --check
cargo clippy --all-targets --all-features -- -D warnings
cargo clippy --all-targets --no-default-features -- -D warnings
cargo clippy --target wasm32-unknown-unknown --lib --tests -- -D warnings
cargo test --all-features                            # unit, golden images, display lists, exporters, CLI
cargo test --release --all-features                  # includes the asserted perf budgets
cargo test --release --test perf -- --nocapture      # 1080x1080 < 8 ms, damage redraw < 2 ms
CARGO_TARGET_WASM32_UNKNOWN_UNKNOWN_RUNNER=wasm-bindgen-test-runner \
  cargo test --target wasm32-unknown-unknown --test wasm   # render + every exporter inside a wasm runtime
cargo bench --bench raster
RUSTDOCFLAGS="-D warnings" cargo doc --no-deps --all-features
```

Golden images: `DESYN_GOLDEN_OUT=/some/dir cargo test --test golden` writes the actual renders (and diffs of
failures); `DESYN_UPDATE_GOLDENS=1 cargo test --test golden` rewrites the expected PNGs (inspect them first).
Fixture inputs are generated by `python3 scripts/gen_render_fixtures.py ../../spec/fixtures/render` (Pillow).

## CLI

```sh
cargo run --release --features cli --bin desyn-render -- design.json --assets assets/ -o out.pdf
```

See `desyn-render --help` and API.md.
