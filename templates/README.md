# @desyn/templates

The template library: 319 editable designs across 19 design kinds, generated by a TypeScript pipeline and stored as
contract-valid `Design` JSON (`docs/DOCUMENT_MODEL.md`) with real copy, named color styles and semantic roles.

| Kind | Count | Kind | Count |
| --- | --- | --- | --- |
| Social post | 77 | Business card (front + back) | 14 |
| Story | 30 | Logo | 14 |
| Thumbnail | 20 | Newsletter (A4 + email header) | 14 |
| Poster | 20 | Invitation | 12 |
| Flyer | 18 | Résumé | 10 |
| Banner | 16 | Menu | 9 |
| Ad (every IAB shape) | 16 | Book cover | 9 |
| Presentation (10 slides, notes, transitions) | 14 | Certificate | 8 |
| Infographic | 8 | Document (3-page proposal) | 8 |

About 40% are marked premium (deterministic per slug).

## How it works

1. **Copy decks** (`src/copy/niches.ts`): 24 fictional businesses and people with real, specific copy (headlines,
   accent phrases, menus with prices, schedules, stats, testimonials, events). No lorem ipsum anywhere.
2. **Design language** (`src/lib`): 24 curated palettes checked for WCAG contrast (`test/palettes.test.ts`), type
   pairings from the shared `@desyn/schema` font catalog, original procedural vector art (`art.ts`) drawn from each
   palette, and a typed builder (`doc.ts`) that emits named color styles (`{ $style }` references, so recoloring a
   template is one edit), roles on every meaningful node, and auto-layout stacks for text so copy of any length keeps
   its rhythm.
3. **Archetypes** (`src/archetypes`): layouts per kind that derive every measure from the page size. Headlines are
   sized to fit their column without splitting words (`fitSize`), and accent-colored small text is darkened until it
   passes contrast (`readable`).
4. **Plan** (`src/plan.ts`, `src/catalog.ts`): which archetype is built for which niche, palette, pairing and page
   preset. Everything derives from the slug, so regenerating is byte-for-byte stable.
5. **Normalize + lint** (`src/lib/engine.ts`): every design goes through the real engine (the same wasm module the
   editor runs) with the actual Google Fonts, which computes derived boxes (text heights, auto-layout, group bounds)
   and runs the design lint. `generate --strict` fails on any lint error (contrast, overlap, overflow, print dpi).
6. **Imagery** (`src/imagery.ts`): 54 original photos generated with fal FLUX 3 (prompts kept as provenance in
   `assets/manifest.json`), plus 2x SeedVR upscales (`<key>@print`) for photos used in print templates so they print
   at about 300 dpi.
7. **Render** (`src/cli/render.ts`): thumbnails (640 px WebP), page previews for multi-page templates and gallery
   previews (`public/`, 560 px) with the `desyn-render` CLI (`crates/desyn-raster`).

## Commands

```sh
pnpm --filter @desyn/templates fonts        # download the Google Fonts the pairings use into .fonts/ (gitignored)
pnpm --filter @desyn/templates imagery      # generate missing photos (needs FAL_AI_API_KEY; read from .env, never printed)
pnpm --filter @desyn/templates imagery --print   # 2x upscales of photos used by print templates
CARGO_TARGET_DIR=target/render cargo build --release -p desyn-raster --features cli --bin desyn-render
pnpm --filter @desyn/templates generate --strict  # designs/*.json + manifest.json (fails on lint errors)
pnpm --filter @desyn/templates render       # thumbnails/ + public/
pnpm --filter @desyn/templates test         # plan, determinism, contract validity, palettes, copy
```

## Publishing

`src/cli/seed.ts` publishes every template through `templates/admin:publish` (pipeline token path): the design JSON,
the photos it references (validated and stored under `templates/<slug>/` in S3) and two thumbnails.

```sh
python3 deploy/scripts/convex-cloud-env.py prod      # creates TEMPLATES_PIPELINE_SECRET_PROD once and sets it on Convex
pnpm --filter @desyn/templates seed --target prod    # or --target dev, or --url <convex url> with TEMPLATES_PIPELINE_SECRET
```

Republishing is idempotent by slug. `--only <slug-prefix>` publishes a subset; `--dry-run` reads everything without
sending.

## Outputs

| Path | What |
| --- | --- |
| `designs/<slug>.json` | normalized design (canonical JSON) |
| `manifest.json` | slug, title, description, kind, preset, size, pages, categories, tags, premium, collections, searchText, colors, fonts, images, thumbnail |
| `thumbnails/<slug>.webp`, `thumbnails/<slug>/<n>.webp` | thumbnails and page previews |
| `public/<slug>.webp` | gallery previews; `apps/landing` copies them at build time (`scripts/copy-template-previews.mjs`) |
| `assets/images/*.jpg`, `assets/manifest.json` | the photo catalog with provenance |
