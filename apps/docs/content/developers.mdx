## Choosing an integration

| You want to | Use |
| --- | --- |
| Let an AI assistant (Claude, an IDE agent) create and edit designs | The [MCP server](/developers/mcp) |
| Automate Desyn from a script, backend or CI | The [Agent API](/developers/api) or the [TypeScript SDK](/developers/sdk) |
| Make precise programmatic edits | [Transactions](/developers/operations) through the API |
| Read a design's structure for your own analysis | [Describe](/developers/describe) |
| Change Desyn itself | The [source](/developers/contributing), under the [license](/developers/license) |

The Agent API and MCP server are part of Pro and the self-hosted edition.
