---
title: Charts, tables & QR
description: Data-driven elements — charts from your numbers, tables with merged cells and styling, and QR codes — that stay editable.
---

Charts, tables and QR codes are real layers, drawn from data you can edit at any time. They are part of Pro and the self-hosted edition; add them from the **Elements** panel.

## Charts

| Type | Good for |
| --- | --- |
| Bar, column, stacked column | Comparing categories |
| Line, area | Change over time |
| Pie, donut | Parts of a whole (keep it to a few slices) |
| Scatter | Relationships between two values |
| Radar | Comparing several attributes |
| Funnel | Stages that narrow, such as a sales pipeline |
| Progress | A single value against a goal |

### Data

Select a chart and open its data in the **Design** tab: a small spreadsheet with labels in the first column and one column per series. Paste straight from a spreadsheet — tab-separated data from Excel, Numbers or Google Sheets fills the grid. Each series can have its own color.

### Appearance

Toggle the legend, gridlines and value labels; set a palette (your brand colors by default), font family and size, text color, an optional minimum and maximum for the axis, and a unit suffix such as `%` or `k`.

The agent can create charts from numbers in your message (*"add a column chart of these quarterly sales: Q1 120, Q2 180, Q3 165, Q4 240"*) or restyle existing ones.

## Tables

Tables have rows and columns with individual widths and heights. Per table you can enable a **header row**, **striped rows**, border color and width, and cell padding; per cell, the text, text style, background fill and alignment.

- Click a cell to type; <Keys combo="tab" /> moves to the next cell.
- Select cells and **merge** them across rows or columns.
- Add or remove rows and columns from the context menu, or drag the table's edge.
- Paste tab-separated data to fill many cells at once.

Text in tables uses a default style for the whole table, which individual cells can override.

## QR codes

A QR code layer encodes any text — usually a URL. Set the foreground and background colors, the error correction level (L, M, Q or H; higher levels survive more damage or a logo placed on top) and rounded modules for a softer look.

> [!TIP]
> Keep enough contrast between the two colors and leave a quiet margin around the code. If you put a logo on top, use error correction **H** and test the printed result with a few phones.
