Any design can be presented, and presentation designs are built for it: 16:9 pages, slide roles for titles and bodies, speaker notes and transitions. Presentations are part of Pro and the self-hosted edition.

## Starting a presentation

Choose **Present** in the top bar, or press <Keys combo="mod+shift+enter" /> to start from the current page. The presentation fills the screen and plays each page's animations and transitions.

| Action | Keys |
| --- | --- |
| Next slide | <Keys combo="arrowright" /> or <Keys combo="space" /> |
| Previous slide | <Keys combo="arrowleft" /> |
| First / last slide | <Keys combo="home" /> / <Keys combo="end" /> |
| Toggle speaker notes | <Keys combo="n" /> |
| Black screen | <Keys combo="b" /> |
| Exit | <Keys combo="escape" /> |

Clicks also advance. Layers with a page link jump to that page, and layers with a URL open it in a new tab.

## Speaker notes

Write notes for each page in the inspector (with nothing selected) under **Notes**. While presenting, press <Keys combo="n" /> for a presenter view with your notes, the next slide and a timer — ideal on a second screen.

## Auto-advance

Give pages a duration to advance automatically, for kiosks and looping displays. Animations and transitions play as configured.

## Presenting from a link

Share a presentation without giving edit access: **Share → Presenter link** creates a `/present/…` URL that opens straight into presentation mode. Like other share links, it can have a password and an expiry date.

## Exporting a deck

Export to **PDF** for handouts or **PowerPoint (PPTX)** to present from other software. PPTX export keeps text editable. See [export](/editor/export).
