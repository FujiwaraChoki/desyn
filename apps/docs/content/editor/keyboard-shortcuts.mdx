Shortcuts are shown for your platform: <Keys combo="mod" /> is Command on macOS and Ctrl on Windows and Linux, <Keys combo="alt" /> is Option or Alt, <Keys combo="shift" /> is Shift. You can always open this list inside the editor with <Keys combo="mod+/" />, and you can run any command by name from the command palette with <Keys combo="mod+k" />.

> [!TIP]
> Shortcuts that use single letters (tools, zoom presets) are disabled while you type in a text layer or an input, so typing never switches tools by accident.

## In the app

Open **Settings → Shortcuts** to see the same list inside Desyn. Every command in the palette also shows its shortcut, which is the fastest way to learn them.
